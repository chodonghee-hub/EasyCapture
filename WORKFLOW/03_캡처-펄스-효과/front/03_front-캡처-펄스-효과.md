## 동작 방식

- 순서: Enter 확정 → PNG 인코딩 → 효과 → 오버레이 닫기 → 보관소 저장 → 알림.
- 길이: 전체 1초(`EffectDuration`), 안전망 타이머는 1.3초, Effect(블러·그림자)는 쓰지 않는다.
- 테두리: 2px에서 피크 7px(DPI 배율 적용)로 200ms에 굵어졌다가 200ms에 복귀(피크 1회), #38A0FF에서 #7CD4FF로 밝아졌다 복귀, 바깥 발광 2겹과 어두운 남색 외곽이 함께 나타났다 사라짐.
- 링: 2개(첫 링 즉시·둘째 링 120ms 지연), 각 500ms에 사방 30px 퍼지며 두께 6px에서 1px, 불투명도는 투명에서 50ms 만에 0.95까지 나타난 뒤 0으로(위치 CubicEase Out, 두께·사라짐 QuadraticEase In), 겹은 옅은 발광(링의 1.7배)·어두운 남색 외곽(바깥 1.5px)·#2E8CFF·안쪽 흰 하이라이트. 두꺼운 겹은 중심선을 바깥으로 밀어 안쪽 가장자리를 파랑 링과 시작·끝에서 같게 맞춘다. 중간에는 위치·두께 이징이 달라 글로우 안쪽이 파랑 링 안쪽보다 최대 약 1.1px×배율 더 안쪽까지 나오지만, 모든 겹의 안쪽 가장자리는 선택 영역 경계 이상이라 선택 영역 안은 칠하지 않는다.
- 혜성 빛: 12시 출발 시계 방향, 둘레 35%·1.6바퀴, 머리 9px에서 꼬리 1.5px, 길이가 다른 겹(코어 32·파랑 10·외곽 8·헤일로 6)을 머리 기준으로 포개 조각 경계 없는 그라데이션(코어 색은 흰색→하늘색→파랑), 이징은 PowerEase(1.1) EaseIn(처음엔 평균보다 약간 느리고 점점 빨라져 100ms에 머리가 상단 변 끝 근처), 경로는 선택 영역 테두리 중심선에 가운데 정렬(극소 영역도 테두리 위), 컨테이너는 10%에 나타나 마지막 15%에 사라짐.
- 방향: 경로를 상단 중앙→우상→우하→좌하→좌상 순서로 만들고 `StrokeDashOffset`을 줄여 시계 방향으로 이동(화면 밖 렌더로 12시→3시→6시→9시 확인).
- 요소 수: 약 67개(`Pulse` 11, `Sweep` 56), 애니메이션 89개, 브러시·경로는 Freeze.
- 작은 영역: 두께를 짧은 변의 1/4 이하(최소 1px)로 제한하고 길이는 둘레 비율이라 1~120px에서도 비정상으로 커지지 않는다.
- 상수(길이·두께·퍼짐·지연·빛 길이·바퀴 수·겹 수·페이드 구간·색)는 모두 `CaptureOverlayWindow` 상단 블록에 모아 두었다.

## 안전 장치

- PNG는 오버레이가 뜨기 전에 찍어 둔 정지 이미지에서 효과 시작 전에 잘라 만들므로 효과가 섞이지 않는다.
- 확정 후(`_finished`) 키·마우스 입력을 모두 무시해 이중 확정, 프리셋 저장, Esc 취소가 불가능하다.
- 포커스를 잃어도 취소 경로가 `_finished`로 막혀 저장은 유지된다.
- 완료 처리는 애니메이션 완료·안전망 타이머(1300ms)·창 닫힘 중 먼저 온 한 번만 실행하고, 이미 닫힌 뒤 호출돼도 예외가 없다.
- 효과 중에는 `_overlay`를 유지해 새 캡처가 효과 화면을 찍지 않는다.
- Windows 애니메이션 설정(`ClientAreaAnimation`)은 효과 분기에 쓰지 않고 항상 효과를 재생한다(`App.xaml.cs` 시작 로그만 값을 읽어 기록한다). 취소 경로에는 효과가 없다.
