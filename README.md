# EasyCapture

단축키를 누르면 미리 정한 영역이 표시되고, Enter로 캡처해 목록에 보관한 뒤, 파일처럼 복사·붙여넣기 하는 Windows 트레이 앱입니다.

## 주요 기능

- 전역 단축키로 캡처 시작, 어두운 오버레이에 지정 영역을 밝게 표시하고 Enter로 캡처 (멀티모니터·DPI 대응 코드 포함, 실환경 검증은 단일 모니터에서만)
- 캡처 영역 프리셋: 이동·크기 조절, 프리셋 전환, 새 영역 지정 후 프리셋으로 저장
- 캡처 보관소: PNG 저장, 이름 변경, 고정, 삭제, 개수·기간 제한
- 클립보드 패널: 썸네일 목록에서 다중 선택 후 파일로 복사, 이전 창에 바로 붙여넣기, 외부 앱으로 드래그 앤 드롭
- 복사 방식: 파일+이미지(기본) / 파일만 / 이미지만 (설정 파일의 `CopyMode` 값)
- 트레이 상주, 중복 실행 방지

## 요구 사항

- Windows 10/11
- .NET 9 SDK (소스에서 빌드·실행할 때. 대상: `net9.0-windows`)

## 설치

아직 설치 파일(Setup.exe)은 없습니다. 설치 파일 방식은 예정입니다.

소스를 내려받아 직접 실행합니다.

```
git clone <저장소 주소>
```

저장소 주소는 공개 후 채워 넣으세요. 폴더를 복사하거나 압축을 풀어 사용해도 됩니다.

## 실행

- 루트의 `run.bat`을 더블클릭하면 Release로 빌드한 뒤 앱을 실행합니다. 트레이 앱이라 창은 뜨지 않으며, 트레이 아이콘으로 확인합니다.
- 또는 명령줄에서 실행합니다.

```
dotnet run --project src\EasyCapture.App\EasyCapture.App.csproj -c Release
```

이미 실행 중이면 새로 실행한 쪽은 바로 종료됩니다 (Mutex 중복 실행 방지).

## 사용법

### 기본 단축키

| 동작 | 기본 키 | 상태 |
|---|---|---|
| 캡처 시작 | `Ctrl+Shift+S` | 동작 |
| 클립보드 패널 열기/닫기 | `Ctrl+Shift+V` | 동작 |
| 마지막 캡처 다시 복사 | `Ctrl+Shift+C` | 예정 (현재 "준비 중" 알림) |

설정 화면이 아직 없어 단축키는 `%APPDATA%\EasyCapture\settings.json`에서만 바꿀 수 있습니다. 프리셋별 전용 단축키도 같은 파일에서 지정합니다.

### 캡처 오버레이

| 키 | 동작 |
|---|---|
| `Enter` | 캡처 |
| `Esc` | 취소 |
| `Tab` / `Shift+Tab` | 다음 / 이전 프리셋 |
| 방향키 | 영역 이동 (`Shift` = 10px) |
| `Ctrl`+방향키 | 영역 크기 조절 |
| `R` | 새 영역 지정 (드래그) |
| `S` | 현재 영역을 새 프리셋으로 저장 |
| 마우스 드래그 | 영역 이동, 핸들로 크기 조절 |

`Enter`로 캡처를 확정하면 선택 영역 테두리에 펄스와 시계 방향으로 도는 빛 효과가 약 0.6초 재생된 뒤 저장됩니다. Windows 애니메이션 효과가 꺼져 있으면 효과 없이 바로 저장됩니다.

### 클립보드 패널

| 조작 | 동작 |
|---|---|
| 방향키, `PageUp/Down`, `Home/End` | 이동 (`Shift` 누르면 범위 선택) |
| `Ctrl+클릭`, `Shift+클릭`, `Ctrl+A` | 다중 선택, 전체 선택 |
| `Enter`, 더블클릭 | 복사 후 이전 창에 붙여넣기 (이전 창이 작업 표시줄·바탕화면 같은 셸 창이거나 자기 창이거나 이미 닫혔으면 붙여넣지 않고 복사만) |
| `Ctrl+C` | 복사만 |
| `Delete` | 삭제 (확인 후 영구 삭제, `Enter`/`Y` 확인, `Esc`/`N` 취소) |
| `F2` | 이름 변경 |
| `Ctrl+P` | 고정 / 고정 해제 |
| 썸네일 드래그 | 다른 앱으로 끌어 놓기 |
| 우클릭 메뉴 | 복사, 붙여넣기, 이름 변경, 폴더 열기, 다른 이름으로 저장, 고정, 삭제 |
| `Esc` | 닫기 (다른 창으로 포커스가 옮겨가도 닫힘) |

### 저장 위치와 기본값

- 캡처 파일: `%LOCALAPPDATA%\EasyCapture\captures` (PNG와 `index.json`)
- 설정 파일: `%APPDATA%\EasyCapture\settings.json`
- 보관 개수 기본 200개, 보관 기간 기본 무제한 (`MaxAgeDays` = 0)

## 개발

```
dotnet build EasyCapture.sln -c Release
dotnet test tests\EasyCapture.Tests\EasyCapture.Tests.csproj
```

- `src\EasyCapture.App` — WPF 화면, 트레이, 오버레이, 클립보드 패널
- `src\EasyCapture.Core` — UI와 무관한 로직 (설정, 단축키, 보관소, 복사 계획)
- `tests\EasyCapture.Tests` — xUnit 단위 테스트

## 현재 상태

- 구현됨: 프로젝트 뼈대·트레이, 설정 저장소, 전역 단축키, 캡처 보관소, 캡처 오버레이, 클립보드 패널
- 클립보드 패널은 코드 구현·단위 테스트·정적 검토까지 끝났고 실제 화면 조작 시험은 아직 하지 않았습니다 (실사용 확인 전).
- 캡처 오버레이 미확인: 멀티모니터·혼합 DPI, 포커스를 못 얻을 때의 취소·알림 표시, 트레이 메뉴로 캡처 시작, 한글 IME를 켠 상태의 입력, 트레이 "종료" 경로의 단축키 해제, 확정 효과의 실제 화면 모양
- 예정: 설정 화면 (M7), 설치 파일 (M8), 통합 검증 (M9)
- 아직 연결되지 않음: 마지막 캡처 다시 복사, 캡처 직후 자동 복사(`AutoCopyLatest`), Windows 시작 시 자동 실행(`StartWithWindows`), 트레이 메뉴 "설정"
